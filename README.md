# processapostle
Process Apostle: Mga Istorya

ProcessApostle is an educational advocacy dedicated to helping Philippine citizens understand processes involving:

- Land transactions
- Land administration and compliance
- Agrarian reform
- Agricultural tenancy
- Land disputes

## Project Objectives

- Publish educational videos
- Develop citizen-friendly process guides
- Organize educational articles
- Provide access to consultancy services

## Development

This repository contains the source code and website content for ProcessApostle.
